## 🎨 Visual Identity & Design Direction

Inspired by contemporary editorial design and bold creative agency aesthetics (*GUT FEELING®*):
- **Theme**: High-contrast, bright editorial aesthetic on clean white (`#FFFFFF`) and warm off-white (`#F7F5F0`) surfaces.
- **Color Palette**:
  - **Soft Black / Primary Text**: `#101010`
  - **Burnt Orange / Primary Accent**: `#D53607` (vibrant badge lozenges, cursor highlights, interactive feedback)
  - **Warm Ivory / Secondary Neutral**: `#E6D5BD`
- **Typography**: Editorial display typography powered by Google Fonts `Syne` for headlines and `Plus Jakarta Sans` for body copy.
- **Interactive Motion System**:
  - Dual-ring custom cursor (`dot` + `lagging follower ring`) with input-caret auto-detection (smoothly hides over form inputs).
  - Ambient micro-particles & cursor-reactive radial light canvas (automatically disabled on touch devices and for users with `prefers-reduced-motion`).
  - Interactive service rows with alternating filled and outlined typography and boundary-adaptive floating media previews.
  - Persistent **Floating Social Contact Bar** with direct WhatsApp conversation and Instagram profile links.

## 🧭 Multi-Page Route Architecture

| Route | Page Description |

| `/` | **Homepage**: Hero composition with signature burnt-orange badge, interactive services showcase, selected work, differentiators grid, 4-stage process roadmap, and closing CTA. |

| `/contact` | **Contact & Inquiries**: Direct communication cards (WhatsApp, Direct Phone, Email, Instagram) and transparent project discovery form. |
| `*` | **404 Page**: Polished recovery page directing visitors back to the homepage or services. |

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vite.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Styling**: Vanilla CSS Design Token Architecture (`tokens.css`, `index.css`) with CSS custom properties and clamp typography.
- **Icons**: [Lucide React](https://lucide.dev/) + Custom inline SVGs for brand social icons.
- **Linter**: [Oxlint](https://oxc.rs/docs/guide/usage/linter.html) (ultra-fast Rust-based linter).

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm, yarn, or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/mayuri2907/VyroBytex.git

# Navigate into project directory
cd VyroBytex

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Linting
```bash
npm run lint
```

### Production Build
```bash
npm run build
```
Generates a minified, production-ready bundle in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
